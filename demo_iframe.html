🤖 Demo Nhúng AI Chatbot qua Iframe

Đây là ví dụ về cách nhúng chatbot vào website của bạn

💬 Chatbot Interface

Giao diện chatbot được nhúng qua iframe:

📝 Cách Sử Dụng

1. Nhúng vào website:

<iframe src="http://localhost:8000/embed" width="400" height="600" frameborder="0" style="border-radius: 10px;"> </iframe>

2. Hoặc truy cập trực tiếp:

http://localhost:8000/

3. API endpoints vẫn hoạt động:

POST http://localhost:8000/api/chat/ GET http://localhost:8000/docs

✨ Ưu điểm:

  • 🚀 Real-time với WebSocket
  • ⚡ Tốc độ phản hồi nhanh
  • 📱 Responsive design
  • 🔌 Dễ dàng nhúng vào website
  • 🔄 Auto-reconnect khi mất kết nối
  • 💬 Typing indicator
  • 📊 Connection status
