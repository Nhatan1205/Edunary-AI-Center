🤖 AI Chatbot - Demo Nhúng vào Website

Tích hợp chatbot AI vào website của bạn chỉ với vài dòng code

💬 Live Demo

💡 Thử chat ngay! Chatbot đang chạy live từ server.

📝 Cách Nhúng vào Website

1. Copy code HTML này:

<!-- Nhúng AI Chatbot vào website -->
<iframe 
    src="http://localhost:8000/embed" 
    width="100%" 
    height="600px"
    frameborder="0"
    style="border: none; border-radius: 12px;"
    title="AI Chatbot">
</iframe>

2. Hoặc dùng JavaScript:

<div id="chatbot-container"></div>

<script>
    const chatbotDiv = document.getElementById('chatbot-container');
    const iframe = document.createElement('iframe');
    iframe.src = 'http://localhost:8000/embed';
    iframe.width = '100%';
    iframe.height = '600px';
    iframe.style.border = 'none';
    iframe.style.borderRadius = '12px';
    chatbotDiv.appendChild(iframe);
</script>

✨ Tính năng:

  • Responsive - Tự động điều chỉnh theo màn hình
  • WebSocket - Streaming response real-time
  • Session management - Lưu lịch sử chat
  • Typing indicator - Hiệu ứng đang gõ
  • Auto-reconnect - Tự động kết nối lại
  • Mobile friendly - Tối ưu cho mobile

🚀 Ví dụ Fullwidth

📌 Lưu ý: Thay http://localhost:8000 bằng URL thực của server khi deploy production.

Code mẫu - Chatbot fullwidth trong container:

<!DOCTYPE html>
<html>
<head>
    <style>
        .chatbot-wrapper {
            max-width: 1200px;
            margin: 0 auto;
            padding: 20px;
        }
        .chatbot-frame {
            width: 100%;
            height: 700px;
            border: none;
            border-radius: 15px;
            box-shadow: 0 8px 32px rgba(0,0,0,0.1);
        }
    </style>
</head>
<body>
    <div class="chatbot-wrapper">
        <iframe 
            src="http://localhost:8000/embed"
            class="chatbot-frame"
            title="AI Chatbot">
        </iframe>
    </div>
</body>
</html>

Tùy chỉnh kích thước:

<!-- Sidebar chat (300px width) -->
<iframe src="http://localhost:8000/embed" width="300px" height="600px"></iframe>

<!-- Standard chat (400px width) -->
<iframe src="http://localhost:8000/embed" width="400px" height="650px"></iframe>

<!-- Large chat (500px width) -->
<iframe src="http://localhost:8000/embed" width="500px" height="700px"></iframe>

<!-- Fullscreen chat -->
<iframe src="http://localhost:8000/embed" width="100%" height="100vh"></iframe>
